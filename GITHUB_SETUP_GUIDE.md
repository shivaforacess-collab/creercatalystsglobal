# 🚀 GitHub Pages Setup Guide
## The Career Catalysts Global (TCCG) Website

---

## 📁 Files You Need
- `index.html` — the main website file
- `logo.jpg` — your TCCG logo

Both files must be in the **same folder**.

---

## STEP-BY-STEP SETUP

---

### STEP 1 — Create a GitHub Account
1. Go to **https://github.com**
2. Click **Sign up**
3. Enter your email, create a password, choose a username (e.g. `tccg2026`)
4. Verify your email address

---

### STEP 2 — Create a New Repository
1. After logging in, click the **➕ (plus icon)** → **New repository**
2. Fill in the details:
   - **Repository name:** `tccg-website` *(or any name you like)*
   - **Description:** The Career Catalysts Global Official Website
   - **Visibility:** ✅ Public *(required for free GitHub Pages)*
   - Check ✅ **Add a README file**
3. Click **Create repository**

---

### STEP 3 — Upload Your Files
1. Inside your new repository, click **Add file → Upload files**
2. Drag and drop both files:
   - `index.html`
   - `logo.jpg`
3. Scroll down, write a commit message: `Add TCCG website files`
4. Click **Commit changes**

---

### STEP 4 — Enable GitHub Pages
1. In your repository, click **Settings** (top menu)
2. Scroll down to **Pages** (in the left sidebar)
3. Under **Source**, select:
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**
5. Wait 1–2 minutes

---

### STEP 5 — Access Your Live Website
Your website will be live at:

```
https://YOUR-USERNAME.github.io/tccg-website/
```

Example:
```
https://tccg2026.github.io/tccg-website/
```

GitHub will show the URL in the Pages settings after it's deployed.

---

## 📸 HOW TO UPDATE GALLERY PHOTOS

The Gallery section lets visitors **upload photos directly in the browser** — no coding needed!

On the live website:
1. Go to the **Gallery** section
2. Click the upload zone or drag & drop images
3. Photos appear instantly in the gallery grid
4. Click any photo to view it full-screen
5. Hover over a photo and click ✕ to remove it

> **Note:** Browser-uploaded photos are temporary (they reset when the page is refreshed). To make photos permanent, add them to the repository folder and update the HTML. OR use a free service like Google Photos / Cloudinary for persistent image hosting.

---

## ✏️ HOW TO EDIT WEBSITE CONTENT

1. Go to your repository on GitHub
2. Click on `index.html`
3. Click the **pencil icon ✏️** (Edit this file)
4. Make your changes (update text, phone numbers, etc.)
5. Click **Commit changes**
6. The website updates automatically in 1–2 minutes

---

## 🔧 OPTIONAL: Use a Custom Domain (e.g. tccg.in)

1. Buy a domain from GoDaddy, Namecheap, or Google Domains
2. In GitHub **Settings → Pages**, enter your custom domain
3. Follow the DNS configuration instructions shown

## 🆘 TROUBLESHOOTING

| Problem | Solution |
|---|---|
| Logo not showing | Make sure `logo.jpg` is uploaded and the filename matches exactly |
| Website shows 404 | Check that Pages is enabled and the branch is set to `main` |
| Changes not updating | Wait 2–3 minutes; GitHub Pages has a short delay |
| Website URL not working | Make sure the repository is set to **Public** |
